## 📖 Sobre o Livro
Uma saga épica de fantasia com 706 páginas e 175 capítulos divididos em duas partes:
- **Parte I** — Ecos do Silêncio (Cap. 0–87)
- **Parte II** — Herdeiros da Luz (Cap. 88–175)

## 🎧 Como adicionar os áudios
1. Baixe o arquivo `audiobook_perfeito.rar` do drive
2. Extraia todos os MP3
3. Renomeie no formato: `cap000.mp3`, `cap001.mp3`, ..., `cap175.mp3`
4. Coloque todos na pasta `audio/`
5. Faça push para o GitHub
