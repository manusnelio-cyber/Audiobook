# Pasta de Áudios do Audiobook

## Formato dos arquivos

Os arquivos de áudio devem ser nomeados no seguinte padrão:

- `cap000.mp3` — Prólogo
- `cap001.mp3` — Capítulo 1
- `cap002.mp3` — Capítulo 2
- ...
- `cap175.mp3` — Capítulo 175

## Formatos suportados
- MP3 (recomendado)
- OGG
- M4A
- WAV

## Observação
GitHub tem limite de 100MB por arquivo e 1GB por repositório.
Para áudios grandes, considere usar Git LFS ou hospedar em serviço externo.
